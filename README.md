#  Parcel Tracker (Kotlin Console App)

A simple Kotlin-based **Parcel Tracking System** that runs in the console.  
This project allows users to:

- Add parcel details (recipient, address, tracking number)
- Record hub updates with status and location
- View full tracking history with timestamps
- Display parcels in a tabular format
- Delete parcels with confirmation for safety

The goal is to demonstrate Kotlin programming fundamentals including:

- Object-Oriented Programming (OOP)
- Working with collections and data classes
- Input/output handling in the console
- Timestamping and state tracking

[Software Demo Video](https://youtu.be/QYZKU1MHWoM)

# Development Environment

* IntelliJ IDEA Community Edition
* Kotlin (JVM)
* Standard Library (no external dependencies)

##  Features

- Add new parcel records  
- Track parcel movement through multiple hubs  
- Display current status and latest location  
- View detailed tracking history  
- Update parcel location and delivery status  
- Delete parcels with confirmation prompt  
- Neatly formatted table display for all records
